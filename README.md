# Valura Frontend Assignment

Frontend technical evaluation repository for the Valura assessment.

## 📌 Overview
This repository contains the frontend assignment implementation for Valura, focusing on modern web development practices, component modularity, and responsive UI design.

## 🛠️ Tech Stack
- **Framework:** React / TypeScript / Vite
- **Styling:** Modern responsive CSS / Tailwind
- **State & Routing:** Client-side state handling and component lifecycle management
